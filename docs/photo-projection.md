# 老照片投影纹理

页面默认开启照片纹理，可用右上角开关与原模型对比；“近看照片贴图”定位到西厢房窗前。

檐口凸起的棕黄棋盘瓷砖带使用按墙面尺寸排列的规则网格，不再直接重复照片条带，避免原照片残留透视使砖缝倾斜。正面与转角端面采用相同砖块尺寸，照片开关不会改变砖缝方向。下方花纹饰带使用参照照片绘制的连续花纹，避免不准确取样产生灰色竖条。

首批覆盖西厢房窗面、窗门之间的墙面、正房局部墙面和檐口瓷砖带。三维结构、窗框轮廓和出水孔仍由模型提供。

第二批按材质推断复用，不表示这些位置出现在原照片中：

后续近景复核已撤下墙面的整块平面叠图，改为下面的连续受光材质取样，消除矩形明暗接缝。西厢房窗面保留单独投影。

- 西厢房白灰墙的局部纹理用于同材质侧墙、檐底、梁、门洞和过道抹灰面。
- 正房窗框的旧木纹用于木门、窗框及木构件，沿原有木纹 UV 方向取样。
- 正房台阶上方的水泥面用于院地、台阶和水泥构件。
- 新增过道照片的花玻璃用于过道隔断和上部玻璃；砖块内部的小片颗粒用于几何砖面，不复制照片中的砖缝。

复用层通过标准光照材质取样，保留原有凹凸、粗糙度、阴影和顶点颜色；矿物材质混合两组连续镜像取样降低接缝感。照片纹理开关同时控制逐面投影和这些复用层。源照片仍含拍摄时的光照，尚未进行严格去光照处理。

`src/scene/homePhotoProjection.js` 保存原照片路径、参考图尺寸、各区域四角坐标（左上、右上、右下、左下）。着色器通过单应矩阵逐面校正透视，直接采样原图；坐标按参考尺寸归一化，兼容保存的全分辨率照片。新增照片位于 `public/home-photos/references/`，原文件未修改。

当前是局部平面投影，不是摄影测量或完整三维扫描。照片中的光照会保留在纹理里；侧视的窗栏深度、未拍摄区域和遮挡处仍依赖建模。取样范围避开人物，照片阴影造成明显矩形接缝的区域不启用。无法据此保证任意视角与原貌完全一致。

验证：`npm test` 包含单应矩阵四角对齐、取样范围和退化输入测试；`npm run build` 验证生产构建。浏览器中检查纹理开关、近景和控制台错误。
