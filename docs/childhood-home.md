# 老家院子：照片参考重建

这是五张用户原照片对应的本地三维空间草案，不是照片测绘、NeRF、Gaussian Splatting 或世界模型自动生成。所有尺寸均为估计。

## 可用入口

- `/#/`：老家院子，可拖动环顾、WASD / 方向键行走、点击方向按钮移动。
- 三个照片参考位置、俯视旋转缩放、五张原照片对照及推断说明。
- `/#/momo`：此前原型保留，原有本地存储与 AI 配置不变。

## 隐私与资源

## 验证

第二轮精修保留原布局：车身改为带轮拱的倒角挤出轮廓，补门缝、后视镜、尾灯与前灯；树枝使用弯曲渐细几何并增加根部过渡；院墙增加轻微错落的压顶砖。新增几何有限值、法线与车辆尺寸边界测试。车辆驾驶室仍为简化模型，不能视为原车精确复刻。

建筑表面精修：砖色、砖缝高度、粗糙度各自生成，避免把浅色砖误当凹槽；灰泥与地面增加细蚀坑、短裂纹和连续颗粒。数据纹理使用线性色彩空间及 512px 分辨率，颜色纹理保持 1024px。车棚改为连续波纹薄板，添加轻微旧铁皮纹理、搭接线和紧固件，外边界不变。主屋墙脚改为不规则水泥边缘；补门铰链、板缝、洗衣机圆角盖板与排水管。窗户照片采样排除衣物区域，避免与三维衣物重复。瓦面使用双面材质，修正低视角下背面剔除产生的尖片外观。所有细节仍是参照照片手工估计。

`npm test` 包含视点可达性、碰撞边界、门洞通行、大步长穿透与贴墙滑动测试。`npm run build` 验证生产构建。视觉效果、实际布局仍需照片所有者校正。
